# ContextSpell

An open-source, context-aware spell checker that catches the errors traditional spell checkers miss — words that are spelled correctly but used wrong (*affect* vs. *effect*, *accept* vs. *except*, *ensure* vs. *insure*).

## Why

Standard spell checkers (Hunspell, etc.) only flag words that aren't in the dictionary. They're blind to **real-word errors** — a correctly spelled word that's still the wrong word for its context. ContextSpell adds a second layer of checking that looks at how likely a word is *given its neighbors*, so it can catch mistakes a dictionary lookup alone never will.

## How it works

- **Unknown-word correction** — for words not found in the dictionary, candidates are generated by letter-based filtering and Damerau–Levenshtein edit distance (via NLTK), then ranked by a blend of word frequency ([wordfreq](https://github.com/rspeer/wordfreq)) and bigram likelihood.
- **Context-error detection** — for words that *are* real, valid dictionary words, ContextSpell scores the sentence's bigram likelihood with that word in place. If a low-scoring word has a same-family alternative (via a hand-built confusion set of commonly mixed-up word pairs) that scores meaningfully better in context, it's flagged as a likely context error.
- **Bigram language model** — trained on the NLTK Brown Corpus, cached to disk (`bigram_counts.pkl`) so it only needs to be built once.
- **Lemmatization** — WordNet lemmatization lets the checker recognize inflected forms (verbs/nouns) that wouldn't otherwise match the dictionary.
- **Scoring** — suggestions are ranked using a weighted combination of frequency and bigram score (40% frequency / 60% bigram).

## Installation

```bash
git clone https://github.com/thehandyman28/ContextSpell.git
cd ContextSpell
pip install nltk wordfreq flask pyspellchecker
```

On first run, ContextSpell downloads the required NLTK corpora automatically (`words`, `brown`, `punkt`, `punkt_tab`, `wordnet`).

## Usage

### Command line

```bash
python main.py
```

This builds the dictionary and bigram model (cached after the first run), prompts you for a string, runs the benchmark comparison against Hunspell, and prints flagged errors with suggestions.

### Web app

```bash
python app.py
```

Then open `http://localhost:5000` in your browser. Paste in text and get back both ContextSpell's and Hunspell's suggestions side by side via the `/check` endpoint, so you can compare context-aware detection against a traditional dictionary-only checker directly.

## Evaluation

`main.py` includes a built-in benchmark (`evaluate()`) that compares ContextSpell against Hunspell across three categories:

1. **Unknown word errors** — typos like *recieved*, *goverment*, *seperate*
2. **Context errors** — correctly spelled but wrong-in-context words like *affect*/*effect*, *insure*/*ensure*
3. **False positives** — correctly spelled, correctly used sentences, to check over-flagging

Hunspell, by design, cannot catch category 2 at all (the words are valid), which is the gap ContextSpell is built to close.

## Confusion set

Context-error detection currently checks against a curated set of commonly confused word pairs (e.g. `affect/effect`, `accept/except`, `elicit/illicit`, `emigrate/immigrate`). Expanding this set is one of the easiest ways to extend coverage.

## Future plans

- **Bigger confusion set** — expand beyond the current hand-built list of commonly mixed-up word pairs to catch a wider range of real-word errors.
- **Replace the Brown Corpus** — move to a larger, more modern corpus for the language model, since Brown is relatively small and dated.
- **Beyond bigrams** — move past bigram-only context scoring (e.g. trigrams or a wider context window) to improve detection accuracy without introducing a neural network.
